CSS Text Alignment

text-align specifies the horizontal alignment of text inside an element.

Left Alignment

CSS Typography improves readability by aligning text to the left. This is the default alignment for most web pages.

Center Alignment

CSS Typography improves readability by aligning text to the center. It is commonly used for headings and titles.

Right Alignment

CSS Typography improves readability by aligning text to the right. It is less common in standard web layouts.

Justify Alignment

CSS Typography improves readability by distributing text evenly across both the left and right margins, creating a clean and professional appearance often used in newspapers and articles.

Syntax

text-align: left;

text-align: center;

text-align: right;

text-align: justify;


Explanation

  • left → Aligns text to the left (default).
  • center → Centers the text horizontally.
  • right → Aligns text to the right.
  • justify → Aligns text evenly on both left and right sides by adjusting spacing.
