CSS Font Weight

font-size changes the size of the text, while font-weight controls how thick or bold the text appears.

Font Size

font-size: 12px

font-size: 18px

font-size: 24px

font-size: 32px

font-size: 40px

Syntax

font-weight: bold;


Explanation

  • font-weight → Makes text thinner or bolder.
  • Common Values: 100, 300, 400 (Normal), 700 (Bold), 900 (Extra Bold).
