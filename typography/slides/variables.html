JavaScript · Variables

Variables Practice

Practice the three ways of declaring variables in JavaScript: var, let, and const. Observe how their values behave when we assign, update, and access them.
01 · var

var allows the variable to be declared again and its value can be changed.

var name = "Srihitha";
name = "JavaScript";
console.log(name);
Output: JavaScript
02 · let

let allows the value to be changed, but the same variable cannot be declared again in the same scope.

let age = 22;
age = 23;
console.log(age);
Output: 23
03 · const

const cannot be reassigned after it has been declared.

const country = "India";
console.log(country);
Output: India
Complete Practice Example
var studentName = "Srihitha";
var studentName = "Student";

let marks = 80;
marks = 90;

const course = "JavaScript";

console.log(studentName);
console.log(marks);
console.log(course);
Quick Practice
var → Can be redeclared and reassigned
let → Can be reassigned, but not redeclared in the same scope
const → Cannot be reassigned or redeclared
