HTML Accessibility

Building websites that everyone can use

What is Accessibility?

HTML accessibility means creating web pages that can be used by everyone, including people with disabilities.

Accessible websites work well with assistive technologies such as screen readers and also support keyboard navigation.

Accessibility helps people who:

  • Have difficulty seeing
  • Have difficulty hearing
  • Cannot use a mouse easily
  • Use screen readers
  • Have difficulty understanding complex interfaces

1. Use Semantic HTML

Semantic HTML elements describe the meaning and purpose of the content.

❌ Less Accessible

<div>My Website</div>

<div>
    Home
    About
    Contact
</div>

<div>
    Main content
</div>

✅ Better

<header>
    <h1>My Website</h1>
</header>

<nav>
    Home
    About
    Contact
</nav>

<main>
    Main content
</main>

Elements such as <header>, <nav>, <main>, <section> and <footer> provide meaning to the page.

2. Use Labels with Form Inputs

Every form input should have a clear label so users and screen readers know what information is required.

❌ Less Accessible

<input
    type="text"
    placeholder="Enter your name">

✅ Accessible

<label for="name">
    Full Name
</label>

<input
    type="text"
    id="name"
    name="name">

3. Use Alt Text for Images

The alt attribute provides a text description of an image.

❌ Less Accessible

<img src="profile.jpg">

✅ Accessible

<img
    src="profile.jpg"
    alt="Profile picture of John">

A screen reader can read the alt text to the user.

4. Use Headings Correctly

Headings create a logical structure for the page.

❌ Incorrect Structure

<h1>HTML Accessibility</h1>

<h4>Semantic HTML</h4>

<h2>Forms</h2>

✅ Correct Structure

<h1>HTML Accessibility</h1>

<h2>Semantic HTML</h2>

<h2>Forms</h2>

<h3>Form Labels</h3>

5. Use Real Buttons

Use the <button> element for actions instead of making a <div> behave like a button.

❌ Less Accessible

<div onclick="submitForm()">
    Submit
</div>

✅ Accessible

<button type="submit">
    Submit
</button>

6. Support Keyboard Navigation

Some users navigate websites using only a keyboard. They use keys such as:

  • Tab
  • Shift + Tab
  • Enter
  • Space
  • Arrow keys

Interactive elements should be reachable and usable using the keyboard.



7. Don't Rely Only on Color

Color should not be the only way to communicate important information.

❌ Not Recommended

<p style="color: red;">
    Error
</p>

✅ Better

<p>
    Error: Please enter a valid email address.
</p>

The word "Error" communicates the meaning even if the user cannot distinguish the color.

8. Accessible Form Example

A good accessible form uses labels, appropriate input types and required fields.



Accessibility Checklist

  • Use semantic HTML elements
  • Use proper heading structure
  • Give images meaningful alt text
  • Use labels for form inputs
  • Use real buttons and links
  • Support keyboard navigation
  • Don't rely only on color
  • Use clear and meaningful text
  • Make forms easy to understand
