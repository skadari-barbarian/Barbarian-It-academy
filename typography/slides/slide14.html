Learning Font Face

## @font-face in CSS 1. **`@font-face`** is a CSS rule used to load custom fonts into a webpage. 2. It allows web developers to use fonts that are not installed on the user's computer. 3. The font file is stored in the project or loaded from a server. 4. The **`font-family`** property assigns a name to the custom font. 5. The **`src`** property specifies the location of the font file. 6. Common font formats include **WOFF, WOFF2, TTF,** and **OTF**. 7. After defining the font, it can be applied using the **`font-family`** property. 8. Using custom fonts improves the appearance and branding of a website. 9. It ensures that the same font is displayed consistently on different devices and browsers. 10. `@font-face` is widely used in modern web development to create attractive and professional-looking websites.
