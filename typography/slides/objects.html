JS OBJECTS

JavaScript Objects

An object is used to store information about one thing using key-value pairs.

Basic Syntax

let student = {
    name: "Srihitha",
    age: 22,
    course: "JavaScript",
    marks: 90
};

Object Properties

Each property has a key and a value. 

name   → "Srihitha"
age    → 22
course → "JavaScript"
marks  → 90

Accessing Object Values

Using dot notation:

console.log(student.name);
console.log(student.age);

Using bracket notation:

console.log(student["name"]);

Changing a Property

student.age = 23;

Adding a Property

student.city = "Hyderabad";

Deleting a Property

delete student.city;

Different Data Types

let person = {
    name: "Srihitha",
    age: 22,
    isStudent: true,
    skills: ["HTML", "CSS", "JavaScript"]
};

An object can contain strings, numbers, booleans, arrays, and other objects.

Nested Objects

let student = {
    name: "Srihitha",

    address: {
        city: "Hyderabad",
        state: "Telangana"
    }
};

console.log(student.address.city);

Array Inside an Object

let student = {
    name: "Srihitha",

    skills: [
        "HTML",
        "CSS",
        "JavaScript"
    ]
};

console.log(student.skills[0]);

Methods

A function stored inside an object is called a method. 

let person = {

    name: "Srihitha",

    greet: function() {
        console.log("Hello!");
    }

};

person.greet();

The this Keyword

let person = {

    name: "Srihitha",

    greet: function() {
        console.log("Hello " + this.name);
    }

};

person.greet();

this refers to the current object.

Array of Objects

let students = [

    {
        name: "Srihitha",
        marks: 90
    },

    {
        name: "Rahul",
        marks: 75
    },

    {
        name: "Anu",
        marks: 85
    }

];

Accessing an object:

console.log(students[0].name);
console.log(students[0].marks);

Objects with Array Methods

Using map():

let names = students.map(function(student) {
    return student.name;
});

console.log(names);

Using filter():

let result = students.filter(function(student) {
    return student.marks > 80;
});

console.log(result);

Important Object Methods

Object.keys() — returns all keys.

console.log(Object.keys(student));

Object.values() — returns all values.

console.log(Object.values(student));

Object.entries() — returns key-value pairs.

console.log(Object.entries(student));

Important Points

  • Objects store data using key-value pairs.
  • Properties can be accessed using dot or bracket notation.
  • Properties can be added, changed, or deleted.
  • Objects can contain arrays and other objects.
  • A function inside an object is called a method.
  • this refers to the current object.
  • Arrays can contain multiple objects.
  • Objects and arrays are commonly used together in JavaScript.
