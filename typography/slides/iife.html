IIFE Practice Page

Immediately Invoked Function Expression

1. Basic IIFE

An IIFE is a function that executes immediately after it is created. 

(function () {
    console.log("IIFE executed");
})();
Output will appear here

2. IIFE with Variables

Variables created inside an IIFE are protected from the global scope. 

(function () {

    let name = "Srihitha";

    console.log(name);

})();
Output will appear here

3. IIFE with Parameters

An IIFE can also receive arguments just like a normal function. 

(function (name) {

    console.log("Hello " + name);

})("Srihitha");
Output will appear here

4. IIFE Returning a Value

An IIFE can execute immediately and return a value. 

let result = (function () {

    return 10 + 20;

})();

console.log(result);
Output will appear here

5. IIFE for Private Data

IIFEs can be used to keep variables private and expose only the required functionality. 

const counter = (function () {

    let count = 0;

    return function () {
        count++;
        return count;
    };

})();

console.log(counter());
console.log(counter());
Counter: 0
