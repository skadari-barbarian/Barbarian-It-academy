CSS White Space & Text Overflow

white-space controls how spaces and line breaks are handled, while text-overflow specifies how hidden text is displayed when it overflows.

Syntax

white-space: nowrap;

text-overflow: ellipsis;


Explanation

  • white-space: normal; → Default value. Text wraps automatically.
  • white-space: nowrap; → Keeps all text on a single line without wrapping.
  • white-space: pre; → Preserves spaces and line breaks exactly as written in the HTML.
  • text-overflow: ellipsis; → Displays ... when overflowing text is hidden.
  • text-overflow: clip; → Cuts off overflowing text without showing an ellipsis.
