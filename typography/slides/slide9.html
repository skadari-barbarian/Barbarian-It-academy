CSS Line Height

line-height controls the vertical spacing between lines of text, making content easier to read.

line-height: 1

CSS Typography improves the readability of web pages. It helps users read content comfortably by controlling the spacing between lines, letters, and words.

Syntax

line-height: 1.5;


Explanation

  • line-height specifies the space between lines of text.
  • Smaller values make lines appear closer together.
  • Larger values increase spacing and improve readability.
  • A value between 1.5 and 2 is commonly used for paragraphs.
