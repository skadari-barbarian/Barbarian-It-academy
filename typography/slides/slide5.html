CSS Font Weight

font-weight specifies the thickness (boldness) of text. Higher values make the text appear bolder.

100 - Thin

900 - Extra Bold

Syntax

font-weight: 700;

font-weight: bold;


Explanation

  • 100 → Thin
  • 300 → Light
  • 400 → Normal (Default)
  • 500 → Medium
  • 700 → Bold
  • 900 → Extra Bold (Black)
