What is CSS Typography?
Definition & Visual Comparison
CSS Typography is the art of styling text on the web using CSS properties. It controls how text looks, feels, and reads — including font choice, size, weight, spacing, alignment, and decoration.
❌ Before — No CSS
This is a heading. This is a paragraph of text with no styling applied. It uses the browser's default font and size.
VS
✅ After — With CSS
This is a heading. This paragraph is styled with a custom font, size, weight, and color for a premium feel.
font-family: 'Playfair Display', serif; font-size: 1.4rem; color: #ffd700; letter-spacing: 1px;

@font-face
Loading custom fonts from your own files
@font-face lets you load a custom font file (like a .ttf or .woff2) from your own project folder, so you don't need Google Fonts or any internet connection.
How it works
1
Download a font file (e.g. Poppins-Regular.ttf) and place it in a /fonts folder.
2
Use @font-face in your CSS to register the font with a name.
3
Use that name in font-family just like any other font.
/* Step 1 & 2: Register the font */ @font-face { font-family: "MyFont"; src: url("./fonts/Poppins-Regular.ttf"); } /* Step 3: Use it */ h1 { font-family: "MyFont"; }
