CSS Color Property

color is used to change the text color of an HTML element. CSS supports different ways to define colors.

Named Color

Hello CSS

color: red;

HEX Color

Hello CSS

color: #3498db;

RGB Color

Hello CSS

color: rgb(46,204,113);

RGBA Color

Hello CSS

color: rgba(231,76,60,0.7);

HSL Color

Hello CSS

color: hsl(280,80%,50%);

Syntax

color: blue;

color: #3498db;

color: rgb(255,0,0);


Explanation

  • Named Colors → Uses predefined color names (red, blue, green).
  • HEX → Uses hexadecimal values (e.g., #3498db).
  • RGB → Uses Red, Green, and Blue values.
  • RGBA → RGB with an Alpha value for transparency.
  • HSL → Uses Hue, Saturation, and Lightness.
