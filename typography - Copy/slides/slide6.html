CSS Font Style & Text Alignment

font-style changes the appearance of text (normal, italic, or oblique), while text-align controls the horizontal alignment of text.

text-align: justify;

CSS Typography improves readability and presentation by evenly distributing text across the width of the container, creating a clean and professional appearance.

Syntax

font-style: italic;

text-align: center;


Explanation

  • font-style: normal; → Displays regular text.
  • font-style: italic; → Displays slanted (italic) text.
  • font-style: oblique; → Displays an artificially slanted version of the font.
  • text-align: left; → Aligns text to the left.
  • text-align: center; → Centers the text.
  • text-align: right; → Aligns text to the right.
  • text-align: justify; → Aligns text evenly along both left and right margins.
