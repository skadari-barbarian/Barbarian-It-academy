CSS White Space & Text Overflow

white-space controls how spaces and line breaks are handled, while text-overflow specifies how hidden text is displayed when it overflows.

Syntax

white-space: nowrap;

text-overflow: ellipsis;


Explanation

  • white-space: normal; → Default. Text wraps automatically.
  • white-space: nowrap; → Prevents text from wrapping to the next line.
  • white-space: pre; → Preserves spaces and line breaks exactly as written.
  • text-overflow: ellipsis; → Displays ... when text is hidden.
  • text-overflow: clip; → Cuts off the extra text without showing dots.
