Font Family

Typography begins with choosing the right font family. Fonts help define the visual personality of a website.

Font Size

Font size controls how large or small the text appears on a webpage.

Font Weight

Font weight controls the thickness and importance of text.

Font Style

Font style can make text italic or visually slanted.

Line Height

Line height controls the vertical distance between lines of text. Good line spacing makes paragraphs easier to read. It is an important part of readable web typography.
