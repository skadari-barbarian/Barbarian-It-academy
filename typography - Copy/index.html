01 · Introduction

What is Express.js?

Express.js is a fast, minimal, and flexible Node.js web framework. It provides a robust set of features for building web and mobile applications. Express makes it easy to create servers, define routes, handle HTTP requests and responses, and use middleware.
Why Express?

✅ Minimal and unopinionated
✅ Fast routing system
✅ Huge middleware ecosystem
✅ Easy to learn and use
✅ Powers millions of apps

Install Express

npm init -y
npm install express

// Your first Express server const express = require('express'); const app = express(); app.listen(3000, () => console.log('Server running!'));
02 · Basics

Express Basics

An Express server needs three things: require express, create the app, and listen on a port. Routes define what happens when a user visits a URL.
⚡ Your Practiced Code

This is the exact code you wrote — a server on port 3000 with a GET route.

const app = require('express')(); const PORT = 3000; app.listen(PORT, () => console.log(`Server is running on port ${PORT}`)); app.get('/getRequest', (req, res) => { res.send('Hello this is a GET Method'); });
app.get()

Handles HTTP GET requests at a specific route path.

req

The request object — contains URL, headers, body, params.

res.send()

Sends a response back to the client (text, HTML, JSON).

04 · Multi-Server

Running Two Servers

You can run multiple Express servers on different ports at the same time. Each port is a separate "door" into your machine. This is useful for microservices or separating frontend and backend.
// server1.js — Port 3000 const app1 = require('express')(); app1.get('/', (req, res) => { res.send('Server 1 — Port 3000'); }); app1.listen(3000, () => console.log('Server 1 on :3000') );
// server2.js — Port 3001 const app2 = require('express')(); app2.get('/', (req, res) => { res.send('Server 2 — Port 3001'); }); app2.listen(3001, () => console.log('Server 2 on :3001') );
Run both at once (two terminals)

node server1.js # Terminal 1
node server2.js # Terminal 2

07 · Security

Browser Security

Browsers enforce the Same-Origin Policy (SOP) — a page can only freely access resources from the same origin (protocol + hostname + port). This prevents malicious sites from reading your data. Iframes from different origins are restricted.
Same Origin ✅

localhost:3000 → localhost:3000

Same protocol, host, and port. Full access allowed.

Cross Origin ❌

localhost:3000 → localhost:3001

Different port = different origin. Restricted by browser.

Clickjacking ⚠️

Attacker embeds your site in an invisible iframe to trick users into clicking hidden buttons.

// Origins compared: // http://localhost:3000 ← protocol: http, host: localhost, port: 3000 // http://localhost:3001 ← DIFFERENT PORT = different origin // https://localhost:3000 ← DIFFERENT PROTOCOL = different origin
08 · Protection

Preventing Iframes

You can stop other websites from embedding your Express app in an iframe using X-Frame-Options or Content-Security-Policy headers. This protects against clickjacking attacks.
X-Frame-Options values

DENY — Nobody can embed this page

SAMEORIGIN — Only same origin can embed

ALLOW-FROM uri — Only specific URL (deprecated)

CSP frame-ancestors

Modern replacement for X-Frame-Options. More flexible — allows multiple origins to be whitelisted.

const app = require('express')(); // Option 1: X-Frame-Options — DENY app.use((req, res, next) => { res.setHeader('X-Frame-Options', 'DENY'); next(); }); // Option 2: CSP frame-ancestors (modern) app.use((req, res, next) => { res.setHeader( 'Content-Security-Policy', "frame-ancestors 'none'" ); next(); });
09 · Middleware

Helmet.js

Helmet is an Express middleware that automatically sets many security-related HTTP headers for you — including X-Frame-Options, CSP, HSTS, and more. It is the recommended way to secure Express apps.
What Helmet sets automatically

✅ X-Frame-Options: SAMEORIGIN
✅ X-Content-Type-Options: nosniff
✅ Strict-Transport-Security
✅ X-XSS-Protection

✅ Content-Security-Policy
✅ Referrer-Policy
✅ Permissions-Policy
✅ Cross-Origin headers

// Install: npm install helmet const express = require('express'); const helmet = require('helmet'); const app = express(); // One line adds all security headers! app.use(helmet()); app.get('/', (req, res) => { res.send('Secured with Helmet!'); }); app.listen(3000);
